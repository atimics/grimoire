# grimoire

**Egregoregramming 101** — a six-week course in designing autonomous avatars in the RATiMICS ecosystem.

> An agent is not a username on a platform — it is a keypair that happens to manifest on many platforms simultaneously.

The grimoire is the discipline of preserving evocative artifacts against entropy. This repo holds the field guide in three forms:

- [`EGREGOREGRAMMING_101.md`](EGREGOREGRAMMING_101.md) — the course, readable on GitHub
- [`EGREGOREGRAMMING_101.typ`](EGREGOREGRAMMING_101.typ) — Typst source
- [`EGREGOREGRAMMING_101.pdf`](EGREGOREGRAMMING_101.pdf) — rendered PDF

## What's inside

18 lessons across 6 weeks (3 lessons/week), with a question set each week, two midterms, and a final exam.

| Week | Lessons | Theme |
|---|---|---|
| 1 | 1–3 | Foundations: soul, sheet, vessel |
| 2 | 4–6 | Voice, spine, surface |
| 3 | 7–9 | The Three-Tier Mind |
| 4 | 10–12 | Patterns, Part 1 (Markdown / Dynamo / Function) |
| 5 | 13–15 | Patterns, Part 2 (Type / Hardcoded / Lineage) |
| 6 | 16–18 | Distribution, Reflex, Discipline |

Read the lesson, do the exercises, then attempt the question set without re-reading.
